# 祥和康养 · 养老服务平台演示原型

> 一个面向养老服务全链条的单文件交互式演示原型：**长者、家属、护理员、机构、监管**五个角色，看同一位长者的不同侧面，讲清"数据如何在养老服务里流动"。

**移动端在线体验**：https://estate77.github.io/Senior-Care/

**PC 数据化系统在线体验**：https://estate77.github.io/Senior-Care/pc.html

## 项目简介

养老服务的难点不在单个 App，而在**角色之间的协同与信任**：长者按了呼叫铃，护理员要能秒级响应；护理员做了服务，家属要能实时看到；机构做了照护，监管要能核验补贴。

本原型用一个连续的叙事串起五个角色的移动端工作台，所有页面围绕同一条主线展开：

> **78 岁的重度失能长者张桂芬（A-302-1 床）的一天** —— 从跌倒告警处置，到家属视频探视预约，到护理员体征速录，到院长经营周报，再到监管科的稽核任务与辖区排行。

每个页面都遵循三条设计原则：

1. **先给结论，再给证据** —— 首屏回答"现在需要我做什么"，细节点开即查；
2. **异常主动找人** —— 告警、复测、待办全部自动推送，不靠人记；
3. **数据一次录入，多方复用** —— 护理员录入的体征同时服务于家属通知、机构风控与监管核验。

## 五个角色

| 角色 | 人物 | 核心页面 | 看到什么 |
|------|------|----------|----------|
| 🦽 长者端 | 张桂芬 · 78 岁 | 首页 / 呼叫中 / 今日安排 | 大字号、大按钮，无菜单设计，只剩"今天有什么事" |
| 👧 家属端 | 李萍 · 女儿 | 今日 / 事件 / 视频探视 / 照护计划 / 账单 / 评价 | 不参与照护，但全程知情：事件时间轴 + 视频探视预约 |
| 👩‍⚕️ 护理端 | 王芳 · 早班 A 区 | 班次 / 任务 / 体征速录 / 批量 / 交班 / 工时 / 告警 | 只看"我这班要做的 9 件事"，异常值自动标红 |
| 🏢 机构端 | 周明 · 院长 | 院长的今天 / 经营周报 / 评估 / 报告 / 排班护理比 / 政策参数 / 账单 | 先看风险与例外，再看经营数据 |
| 🏛️ 监管端 | 王科长 · 区民政局 | 辖区总览 / 稽核任务 / 证据链 | 数据决定去哪里查，而不是靠抽签和投诉 |

## 功能亮点

### 角色与导航
- **屏内右上角账号切换**：五个角色一键切换，每个角色带身份说明
- **页内二级页签**：每个角色的多页面在顶部胶囊页签间切换
- **消息中心**：顶栏铃铛进入，跨角色聚合"需要你行动"的消息，未读角标实时更新

### 各端新增能力
- **视频探视**（家属端）：避开集中照护时段的预约制探视、约满置灰、紧急呼叫通道、探视回看
- **体征速录**（护理端）：血压 / 血糖 / 体温 30 秒录入，超阈值（高压 ≥150、血糖 ≥7.0、体温 ≥37.3）自动标红并同步护士站与家属端
- **经营周报**（机构端）：4 项 KPI + 近 8 周床位使用率趋势 + 收入构成 + 本周结论
- **辖区总览**（监管端）：全区 4 项核心指标 + 机构服务质量排行（满意度 40% + 事件率 30% + 报告及时率 30%），点击机构直达稽核任务

### 叙事级演示流程
- **跌倒告警升级链路**：呼叫 → 1 分 35 秒到场 → 护士复核 → 家属同步 → 监管报送，可切换"正常 / 升级"双时间线
- **补贴证据链**：服务工单 → 影像留痕 → 护士站复核 → 监管核验 → 补贴核减，四段证据环环相扣
- **长护险账单**：自费 / 医保 / 长护险 / 政府补贴四分法，对照政策参数实时试算

### 演示工具
- **纯净模式**：隐藏演示控制台，适合投屏与截图
- **自动演示**：预设 8 步导览路径，自动走完五角色叙事主线
- **一键重置**：所有演示状态恢复初始值

## PC 端数据化系统

除移动端五角色演示外，仓库还包含一个独立的 **PC 端后台演示**（`祥和康养数据化系统.html`，线上入口 `pc.html` 内嵌加载、地址栏保持无中文）：

- **官网门户 + 登录**：机构介绍、服务方案、支付方式、团队与荣誉，五个角色一键登录
- **机构数据**：床位地图（在住/预约/闲置/维修/隔离五态）、老人档案 30 条、入住/退住全流程
- **护理服务**：国标 GB/T 42195-2022 双标准评估（民政 26 条目 + 长护险）、照护计划
- **支付结算**：自费 / 医保 / 长护险 / 政府补贴四分法，居家养老优惠券池管理
- **监管协同**：数据一次录入多方复用，与移动端监管端叙事闭环
- **视觉体系**：暖纸色底 + 松绿品牌色 + 祥和橙操作色，Poppins/Lora 字体层次，纯前端单文件零依赖

## 技术实现

- **零依赖单文件**：纯 HTML + CSS + 原生 JavaScript，无框架、无构建、无外部资源请求，可直接双击打开
- **移动优先**：390px 手机壳内演示，≤430px 自动切换为全屏模式
- **CSS 变量设计系统**：统一色板（护理工卡绿 + 暖橙强调色）、字号、间距、圆角
- **微动效**：页面切换 fadeUp 入场、卡片分层渐现、按钮触感反馈
